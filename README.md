## Project Overview
This repository contains an interactive **ASP.NET Core MVC** self-assessment reviewer application created for the IT Elective 2 Prefinals Examination. The application features live scoring, instant feedback, interactive multiple-choice selection, and explanation toggles for 20 exam items covering core ASP.NET Core and Entity Framework Core topics.

---

## Coverage Topics
1. **Relational Data Modeling & EF Core** (Questions 1–5)
2. **Conceptual Data Architecture & Relationships** (Questions 6–10)
3. **Data Normalization & Integrity** (Questions 11–16)
4. **SQL Operations, Exception Handling & HTTP Standards** (Questions 17–20)
